# 토큰 기반 날짜 예약 — 설계 결정과 운영 가이드

> 상태: **구현 완료** (예약 방식 스위치 뒤). 2026-10 논의 결과. 이전의 "월 신청/자유이용을 한 토큰 예산으로" 구상은 아래 내용으로 대체됐다.

## 1. 구조
- 날짜·시간 한 칸이 예약 한 건(`bookings`). 같은 칸은 한 명만 (`uq_booking_slot`).
- 토큰은 장부(`token_ledger`)의 합이 잔액이고 최소 단위 1의 정수.
- 예약 방식 스위치(`reservation_mode`): `legacy`(기존 월 신청 + 자유이용) → `beta` → `token`.
  관리자는 어떤 방식에서도 `/book`으로 토큰 예약을 미리 써볼 수 있고 토큰이 차감되지 않는다.

## 2. 규칙
- 시간당 토큰(관리자 화면에서 수정): 00~04시 1, 04~08시 0, 08~12시 1, 12~16시 2, 16~24시 4.
- 0토큰 시간대는 토큰이 1개 이상 있는 회원만 예약할 수 있다.
- 새벽(0~4시)은 회원별 허용 체크(기본 허용).
- 예약 가능 범위: 오늘 ~ 이번 달 말. 다음 달은 기존 월 신청 오픈 시각(자동/수동 설정을 그대로 사용) 이후 전체.
- 취소 환불은 시작까지 남은 시간별 단계(관리자 수정). 기본은 시작 전까지 100%. 소수점은 버림. 가장 늦은 단계보다 늦으면 취소 불가.
- 관리자 강제 예약·취소는 토큰·범위·새벽 권한을 따지지 않고, 취소 시 환불 방식(정책대로/전액/없음)을 고른다.

## 3. 토큰 소멸
- 충전·지급된 토큰은 받은 날부터 3개월(`token_expiry_months`) 쓰지 않으면 사라진다. 쓰는 동안은 계속 이월된다.
- 사용은 먼저 사라질 지급분부터 차감. 환불 토큰은 원래 차감한 지급분의 소멸 시각을 이어받는다.
- 상품/지급에 "사용 기한"을 주면 그 시각에 소멸한다. 날짜만 주면 그날 끝(다음 날 0시), 날짜+시각(`YYYY-MM-DDTHH:MM`, KST)이면 정확히 그 시각. 소멸 시각이 없는 옛 지급분은 사라지지 않는다.
- 기한이 지난 무료 상품은 목록에서 사라지고 요청도 거부된다. 지난 기한으로 일괄 지급·조정은 할 수 없다.
- 11월 한정 무료분은 **12월 예약이 열리는 시각**(11월 말 월 신청 오픈 시각)을 기한으로 한다. 관리자 화면의 "베타 달이 끝나는 예약 오픈 시각으로" 버튼이 그 값을 채워준다. 기한은 발급할 때의 값으로 고정되므로, 오픈 시각을 나중에 바꾸면 새로 지급할 때 다시 맞춘다.

## 4. 충전
- 회원이 상품을 고르면 요청(pending) → 관리자가 입금 확인 → 장부에 지급. 상품(가격→토큰)은 관리자가 추가·수정·삭제.
- 바로 지급 상품(`auto_confirm`): 요청 즉시 지급(`confirmed_by='auto'`). 입금 알림 자동 확인(단축어 → 웹훅)을 붙일 때도 `confirm_purchase(..., 'auto')`를 쓰면 된다.
- 대상(`audience`): 전체 / 자유이용 회원만(`role='free'`, 주 5시간 이상 요금제).

## 5. 베타 (11월)
- 월 신청은 기존 방식 그대로. 회원의 자유이용 신청은 막고 토큰 예약이 대신한다.
- 기존 월 신청은 `beta_month`의 매주 같은 요일·시간에 적용된다. 토큰 화면에서는 "월 신청"으로 표시되고 취소할 수 없다.
  토큰으로 예약된 시간에는 월 신청을 만들 수 없고, 월 신청 시간은 토큰으로 예약할 수 없다.

### 운영 순서
1. 관리자 → 토큰 탭 → 예약 방식 "베타" + 적용할 달(예: 2026-11).
2. 4시간 회원: "무료 일괄 지급"(예: 10토큰, 사용 기한 = 베타 달이 끝나는 예약 오픈 시각).
3. 6시간 이상 회원: 상품 추가 — 금액 0, 바로 지급 + 자유이용 회원만, 사용 기한 = 베타 달이 끝나는 예약 오픈 시각.
4. 12월 신청 전 정식 전환: 예약 방식 "토큰 예약". 11월 한정분은 사용 기한이 지나 자동으로 사라진다.

## 6. 남은 일
- 12월 정식 런칭 안내문, 가입/이용 안내 문구를 토큰 방식으로 정리.
- 입금 알림 자동 확인 웹훅(선택).
- 베타 중 발견되는 문제 개선.
- 폰에서 끌어서 선택(길게 눌러 시작) — 지금은 마우스만 끌기, 터치는 탭 선택.
