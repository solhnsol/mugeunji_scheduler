# 토큰제 + 날짜 기반 예약 개편 계획 (구상 단계)

> 상태: **구상 완료, 구현 전**. 2026-10 논의 내용을 정리한 문서. 구현 시작 전에 아래 "정해야 할 것"을 확정한다.

## 1. 왜 바꾸나
- 지금은 월 신청과 자유이용이 같은 시간표(`reservations`, `UNIQUE(요일, 시간)`)를 쓰지만 규칙·화면·한도가 따로다.
  - 월 신청: 요일·시간 **반복 패턴**(날짜 없음), 요금제 시간만큼, 매달 초기화.
  - 자유이용: 24시간 신청 창, 매주 초기화, 시간 한도 없음, 5시간 이상 요금제는 자동 권한.
- 목표
  - 월 신청 + 자유이용을 **하나의 토큰 예산**으로 관리한다.
  - 월 신청은 "루틴 이용자 특권"(더 비쌈), 자유이용은 한 달 캘린더에서 날짜를 골라 신청(휴가 일정 등).
  - 안 오는 월 신청을 취소/환불 규칙으로 줄이고, 취소된 칸은 자유이용에 풀어준다.

## 2. 확정된 규칙

### 2-1. 칸당 토큰 (1시간 기준)
| 시간대 | 자유이용 | 월 신청 |
|---|---|---|
| 12~24시 | 1 | 2 |
| 07~12시 (아침 반값) | 0.5 | 1 |
| 00~07시 (새벽, 7시간 한 덩어리) | 3 | **불가** (자유이용 전용) |

- 새벽은 6h 요금제 이상(또는 요금제 옵션 "새벽 허용") 회원과 관리자만 신청 가능.
- 토큰 단위는 0.5. 월 신청은 같은 요일·시간이 5번 있는 달의 **5번째는 토큰 없는 덤**.
- 관리자 강제 등록은 토큰을 따지지 않는다.

### 2-2. 취소·환불
- 월 신청(날짜별 취소): 7일 전까지 100%, 24시간 전까지 50%, 이후 0%.
- 자유이용: 24시간 전까지 100%, 이후 0%.
- 취소한 칸은 즉시 풀려 다른 회원이 자유이용으로 신청 가능. 시작 시각이 지난 예약은 취소 불가.

### 2-3. 신청 순서와 일정
- 월 신청 오픈: **말일 전날 21:00**
- 자유이용 오픈(= 월 신청 마감): **말일 21:00**
- 관리자 메뉴에서 쉽게 수정(말일 N일 전 몇 시 형식 + 다음 달 실제 날짜 미리보기 + 특정 달만 날짜 직접 지정), 사용자 화면에 두 일정과 카운트다운 안내.
- 입금 확인은 월 신청 오픈 **전에** 끝나 있어야 한다(지금과 같은 방식). 늦게 입금한 회원은 월 신청 창을 놓치고 자유이용만 가능.
- 그 달 요금 입금 확인 후에만 해당 달 예약 가능.

### 2-4. 예산
- 월 토큰 예산은 요금제로 정해진다. 안: 요금제 시간 × 8 (4h → 32, 6h → 48, 8h → 64). **미확정**.
- 월 신청만 쓰면 지금과 동일(4h = 주 4시간). 월 신청을 덜 쓰면 남은 토큰으로 자유이용.
- 같은 요금이면 자유이용만 쓰는 회원은 월 신청 회원의 2배 시간을 쓸 수 있다(의도). 요금제 가격표 점검 필요.
- 쓰지 않은 토큰은 달이 끝나면 소멸(이월 없음).
- 월 0h 계정은 예산 0 → 신청 불가(임시 차단용으로 보고 그대로 둠). **배포 전에 회원 탭의 '자유전용' 계정을 점검**할 것.

### 2-5. 자유이용 화면
- 한 달 달력(날짜별 남은 칸) → 날짜를 누르면 하루 타임라인(아침/새벽 가격 표시) → **날짜 범위 + 시간 일괄 신청**(예: 10/5~10/12 14~18시).
- 화면 상단에 남은 토큰 상시 표시.

## 3. 요금제 개편 (소액 요금제 포함)
- 요금제 = 이름, **월 토큰**, 가격, 옵션(새벽 허용 / 월 신청 허용). 기존 `allowed_hours`(주당 시간)는 월 토큰으로 대체.
- 기존 4/6/8h → 32/48/64토큰. 새벽 허용은 6h·8h에 켠다. "5시간 이상 자동 자유이용 권한" 규칙은 폐지.
- 1만원·2만원 같은 소액 요금제를 토큰 묶음으로 추가. 가격 단가표(토큰당 단가, 큰 요금제일수록 낮게)를 만들어 정한다.
  - 예시(가정): 4h(32토큰)가 4만원이면 토큰당 1,250원 → 1만원 = 8토큰, 2만원 = 16토큰.
- 관리자 요금제 편집 화면 필요: 이름·토큰·가격·옵션 수정, 새 요금제 생성, 판매 중지(기존 회원은 유지).
- 요금제 선택 카드는 현재 3열 고정 → 5개 이상 대응 필요.

## 4. 구현 단계 (각각 별도 PR)
1. **날짜 기반 예약 전환** + 주 단위 시간표 화면. 기존 월 예약은 이번 달 날짜 예약으로 변환. `reservations`에 날짜 추가, `UNIQUE(날짜, 시간)`.
2. **토큰 도입**: 요금제를 토큰 묶음으로, 시간대별 요금표, 신청·취소 시 차감·환불, 새벽 자격 옵션.
3. **일정·관리자 설정**: 월 신청/자유이용 오픈 일정, 관리자 요금제 편집, 사용자 안내.
4. **자유이용 캘린더**: 한 달 달력, 날짜 범위 선택, 토큰 표시.

### 전환 시기
- 사용자에게 보이는 전환은 한 번에, **월 신청 오픈에 맞춰** 한다. 오픈일은 말일 전날 21:00.
- 권장: 이번 달(10월분)은 현행 유지, **12월분 오픈(11/29 21:00)에 전환**. 그 사이 단계별 검증과 회원 공지.
- 자동화 설정 탭(주간 자유이용 초기화, 24시간 신청 창 등)은 새 일정 설정으로 단순화된다.

## 5. 정해야 할 것
1. 현재 요금제 가격 → 토큰 단가표.
2. 월 예산 공식(요금제 시간 × 8)이 맞는지.
3. 소액 요금제에 월 신청을 허용할지.
4. 중간에 가입한 회원의 그 달 토큰: 일할 계산 vs 전액(요금만 조정).
5. "새벽은 월 신청 불가(자유이용 전용)" 해석 확인.
6. 기존 자유이용 전용(월 0h) 계정 처리.

## 6. 참고 (현재 코드 사실)
- 예약 테이블은 하나, 같은 칸은 월/자유 중 한 명만 가질 수 있음(자유이용 신청은 이미 예약된 칸을 거절).
- 5시간 이상 요금제는 `free` 역할을 자동으로 받음(`role_from_hours`). 새벽(0~3시)은 이 역할만 월 신청 가능.
- 월 신청 오픈은 자동화 설정(`monthly_open_*`)에서 하루만 정하는 방식. 자유이용은 `free_booking_*`(24시간 창)와 주간 초기화.
