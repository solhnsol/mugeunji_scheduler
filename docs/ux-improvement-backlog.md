# UX 개선 후보 목록

> 기준: 최신 작업(토큰 예약 `/book` 시간표·앱 셸·PWA, PR #11~#15) 코드를 먼저 읽고, 그 위에서 발견한 것을 우선순위로 정리했다.
> 영향(★ 1~3) = 사용자가 체감하는 정도, 비용(S/M/L) = 구현 크기. `docs/ui-principles.md`의 원칙(레이아웃 안정성·비활성으로 두기·고정 액션 바·상태는 같은 자리에서)을 그대로 따른다.

## B. 예약 화면(시간표) 세부 인간공학

1. **하루 보기 날짜 스트립 스와이프**: 좌우 스와이프로 전날/다음 날 이동(현재는 ‹ › 버튼과 7칸 스트립뿐). 스트립 자동 가운데 정렬. — `BookingPage.tsx` / M
2. **한 주 보기 타깃 크기**: 행 높이 30px·열 폭 `1fr/7`이라 폰에서 한 칸 약 40×30px로 정밀 탭이 어렵다. 폰 기본은 "하루"(이미 그렇게 시작), 한 주는 핀치/가로 스크롤 허용 또는 3일 보기 추가. — `TimeGrid rowHeight` / S
3. **오늘로 이동 버튼 + "지금" 위치 자동 스크롤**: 지금은 7시 고정(`scrollToHour={7}`). 오늘이면 현재 시각 −1시간, 다른 날이면 가장 이른 빈 시간대로. 헤더에 "오늘" 칩. — `TimeGrid`, `BookingPage` / S
4. **시간 가격 구간 시각화**: 가격 밴드(0·1·2·4토큰)를 시간 축 옆의 색 띠로 보여주면 "싼 시간 찾기"가 쉬움. 현재는 `1t` 글자만 작게(9px). — `TimeGrid` 시간 축 / S
5. **작은 글자**: `text-[9px]~[11px]`가 22곳. 모바일 가독성 기준(최소 12px, 대비 4.5:1)에 못 미치는 곳이 있음(`ink-faint #949494` on 흰 배경은 대비 약 3:1). 중요 정보(토큰, 시간)는 12px+, faint 색 상향. — 전역 / M
6. **선택 합계의 위치 근접성**: 필요 토큰·보유·예약 후 잔액이 12px 한 줄 슬롯에 몰려 있어 길면 잘림(`truncate`). 보유/차감/잔액을 3칸 숫자 레이아웃으로 분리. — `BookingPage` 하단 바 / S
7. **내 예약 블록 상세**: 블록 탭이 곧 "취소 선택"이라 정보 확인(환불 금액, 예약 시각)이 불가. 길게 누르거나 상세 시트 제공. — `TimeGrid` / M
8. **월 달력 점유 막대 확대**: 24분할 5px 막대는 폰에서 거의 안 보임. 높이 ↑ 또는 "오전/오후/저녁" 3구간 요약 + 빈 시간 수 숫자("빈 14h"). — `MonthCalendar` / S
9. **"내 예약" 목록**: 날짜별 시간만 보여줌. 다가오는 예약 D-day("내일 14~18시"), 지난 예약은 접기, 캘린더(.ics) 추가 버튼. — `BookingPage` 내 예약 / M
10. **달력 월 이동 스와이프 + 선택일 하이라이트 유지**. — S

## C. 전체 앱 공통

1. **전환 애니메이션**: 라우트 전환·모달 등장이 즉시 변경이라 투박함. 모달은 아래→위 슬라이드(`translate-y` + 배경 페이드), 달력↔일정표는 짧은 크로스페이드(120~180ms). `prefers-reduced-motion` 존중(현재 전혀 없음). — `index.css` / S
2. **포커스 표시**: `focus-visible` 스타일이 `.input`에만 있고 버튼·칸에는 없음. 키보드 사용자에게 현재 위치가 안 보임. 전역 `:focus-visible` 링 정의. — `index.css` / S
3. **다크 모드**: `color-scheme`/다크 팔레트 없음. 밤(자정~새벽 작업실 사용 시간대)에 흰 화면이 눈부심. 디자인 토큰이 이미 `@theme`로 분리돼 있어 확장 쉬움. — `index.css` / M
4. **오프라인·재연결 안내**: WebSocket이 끊기면 3초 간격 재연결만 하고 사용자는 모름 → 실시간 갱신이 멈춘 걸 모른 채 낡은 화면으로 예약 시도. 연결 끊김 배지, 탭 복귀(`visibilitychange`)·재연결 시 즉시 새로고침. 지수 백오프. — `useReservationSocket.ts` / S
5. **PWA 보강**: 매니페스트는 있으나 서비스 워커가 없어 홈 화면 추가 후 오프라인/느린 망에서 빈 화면. 정적 자산 캐시 + 마지막 예약 현황 표시. `shortcuts`(예약, 토큰)로 아이콘 길게 눌러 바로가기. — `public/manifest.webmanifest` / M
6. **번들 분할**: `React.lazy`/`Suspense` 없이 모든 페이지(관리자 989줄 포함)를 한 번들로 로드. 회원은 관리자 코드를 받지 않게 라우트 단위 분할. 웹폰트(Google Fonts)도 `font-display: swap` 확인·가능하면 self-host로 FOUT·외부 의존 제거. — `App.tsx`, `index.html` / S
7. **데이터 패칭**: 페이지마다 `useEffect`+`fetch`로 중복 호출(`BookingPage.refresh`가 config·calendar·week·mine을 매번 4개 동시). 캐시/중복 제거(SWR 형태의 작은 훅), 주 이동 시 이전·다음 주 프리페치로 ‹ › 즉시 반응. — `hooks/` / M
8. **페이지 제목**: 모든 라우트 `document.title`이 동일. 라우트별 제목("예약 · 묵은지") — 탭/히스토리 구분. — S
9. **빈 상태·오류 상태 일러스트/행동 유도**: "불러오지 못했어요"만 있고 재시도 버튼이 없는 화면이 있음(BookingPage error는 홈/로그아웃뿐). 재시도 추가. — `BookingPage`, `TokensPage` / S
10. **로그인 후 원래 가려던 곳으로**: `/book`에서 로그인 화면으로 보낸 뒤 항상 `/`로 돌아감. `?next=` 복귀. — `App.tsx`, `pages/auth.tsx` / S
11. **세션 만료 UX**: 401이면 곧바로 `window.location.reload()`로 입력 중이던 선택이 사라짐. 안내 토스트 후 로그인 → 복귀. — `api.ts` / S
12. **폼 입력 편의**: 전화번호 `inputMode="tel"` 일부만 적용, 숫자 입력(`type="number"`)에서 스크롤 휠로 값이 바뀌는 문제 방지, 제출 중 버튼 비활성+스피너, 엔터 제출·자동 포커스 일관화. — `pages/auth.tsx`, Admin* / S

## D. 미적 완성도

1. **타이포 위계 정리**: 제목/본문/보조 크기가 화면마다 제각각(`text-sm`, `[11px]`, `[10px]` 혼재). 4~5단계 스케일을 토큰으로(`--text-xs` 등)로 고정.
2. **색 의미 체계**: 위험색 `#c45c5c`, 경고 `#b04040`, 현재 시각 `#d0463c` 등 하드코딩 헥스가 흩어짐 → `--color-danger`, `--color-now` 토큰화(다크 모드 대비).
3. **버튼 일관성**: 하단 바의 취소 버튼은 `.btn-danger` 대신 인라인 클래스 복제(`BookingPage`, `ConfirmDialog`). `.btn-danger`로 통일하고 `btn-sm/btn-lg` 변형 추가.
4. **누름 피드백**: `.btn-*`의 `active:scale` 외에 시간표 칸은 누름 시 즉시 색 반응이 없음(hover만). `active:` 스타일 + 선택 시 미세한 스케일/체크 아이콘(색만으로 구분하면 색각 이상 사용자에게 불리).
5. **상태 색 이외 단서**: 내 예약/예약됨/월 신청/선택을 색으로만 구분 → 아이콘·패턴 병행(월 신청은 이미 줄무늬). 범례를 토글 가능한 시트로(10px 범례 제거).
6. **빈 칸 vs 지난 시간 구분**: 둘 다 연한 줄무늬라 구별이 약함. 지난 시간은 더 흐리게/가로줄 제거.
7. **랜딩 이미지**: `webp`·`loading="lazy"` 적용은 되어 있으나 `width/height`(또는 aspect-ratio) 지정이 없어 로딩 중 레이아웃이 밀릴 수 있음. LCP 이미지는 `fetchpriority="high"`.
8. **헤더 정보 밀도**: `/book` 헤더에 토큰 + 홈 두 개만. 토큰 잔액 칩을 헤더 우측에 알약 모양 + 충전 아이콘으로 눈에 띄게, 홈 링크는 앱 로고 탭으로 통합.

## E. 관리자 화면

1. 989줄 `AdminPage.tsx` 단일 파일 → 탭별 분리 + lazy 로드(성능·유지보수).
2. 표/목록에 **검색·정렬·필터 유지**(URL 쿼리)와 키보드 이동. 대량 작업(일괄 지급)은 확인 요약(대상 N명, 총 토큰) 후 실행.
3. 관리자 일정표에 **회원 이름 자동완성**(select → combobox), 강제 예약 후 "방금 한 작업 되돌리기".
4. 입금 확인 목록: 새 요청 도착 알림(웹소켓 이미 존재)과 배지 카운트, 처리 후 다음 항목으로 자동 이동.
